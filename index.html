Карта Генов - Справка
Назначить здания
1. Выбери союз - нажми на его кнопку в панели
2. Режим "Назначить" - кликай на здания
3. Режим "Очистить" - снять назначение
4. Стрелки в углу карты - отмена / повтор
Фильтр союза
Кнопка глаза рядом с кнопкой союза - останутся только его здания. Повторно - снять.
Цель
1. Выбери союз, нажми "Цель", кликни на здание
2. Появятся 2 кратчайших пути с очками под картой
3. Повторный клик на цель - стирает
Цели атаки
Режим "Цели атаки" - кликай здания для отметки. Под картой появится редактируемый текст для рассылки.
Инфо
Режим "Инфо" - кликни на здание, всплывает окно прямо на карте: тип, очки, союз, центр/крюк, захват.
Планы
Сохрани до 10 вариантов. Введи название - "Сохранить". Экспорт/Импорт JSON - для обмена планами с другими.
Подписи
Кнопка "Подписи" - показать/скрыть названия зданий на карте.
Поиск
Введи название - нажми на результат - здание подсветится золотым кольцом.
